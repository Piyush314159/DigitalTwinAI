01 / MEASUREMENTS

A physical hydraulic test rig.

The downloaded UCI dataset contains 2,205 measured 60-second cycles. Fourteen physical channels measure pressure, flow, temperature, vibration and motor power.

Three supplied derived channels (CE, CP and SE) are excluded from model inputs. No simulator readings are used.

Dataset source and documentation

Helwig, Pignanelli & Schütze (2015) · UCI Machine Learning Repository · CC BY 4.0 · DOI 10.24432/C5CW21

02 / CLASSIFICATION

Four documented component conditions.

The model estimates cooler efficiency, valve condition, internal pump leakage and accumulator pressure class. Labels come from profile.txt and are never used as sensor features.

Each sensor contributes its mean, standard deviation, minimum, maximum and six ten-second means: 140 compact features per cycle. A linear classifier and small neural network are compared.

03 / EVALUATION

Held-out condition combinations.

All cycles with the same joint four-component condition combination stay together in a single partition. This prevents repeated examples of the same combination appearing across training and test sets.

Normalization and class weights use training only. Validation chooses the deployed model. The test set is scored after selection. This is a same-rig experiment, not a chronological future forecast.
