# Downloaded UCI hydraulic measurements

Place the extracted dataset in `condition+monitoring+of+hydraulic+systems/`, retaining its original `profile.txt`, physical sensor files, description and documentation.

Source: https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems

Helwig, N., Pignanelli, E. & Schütze, A. (2015). DOI: 10.24432/C5CW21. CC BY 4.0. Original downloaded files are unchanged.

`processed/` is a generated feature/trace cache; it can be deleted and rebuilt from the raw measurements. Both the raw download and processed cache are ignored by Git. Only the project README and provenance/metric reports should be versioned.
